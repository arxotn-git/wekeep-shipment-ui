요미몬 출고 집계

이 페이지의 새 즐겨찾기로 한 번만 교체하세요. 이후 버튼·기능 변경은 다시 설치하지 않아도, 다음 즐겨찾기 실행 때 반영됩니다.

처음 한 번만 교체

  1. 크롬에서 Ctrl + Shift + B를 눌러 즐겨찾기 바를 표시합니다.
  2. 아래 파란 버튼을 즐겨찾기 바에 끌어다 놓습니다.
  3. 기존 ‘요미몬 출고 집계’ 즐겨찾기는 삭제하고 새 즐겨찾기를 사용합니다.
요미몬 출고 집계 (자동)

최신 코드 연결 주소를 준비하고 있습니다.

매번 사용하는 방법

  1. 위킵에 본인 계정으로 로그인합니다.
  2. 로그인하신 위킵 탭에서 즐겨찾기를 다시 클릭합니다. 크롬 새 탭·주소 설정 화면에서는 즐겨찾기 코드와 안내문이 실행되지 않습니다.
  3. 기간·상품을 정하고 검색을 누릅니다. 상품명을 비우면 전체 상품을 조회합니다.
상품·수량은 검색할 때마다 위킵에서 읽습니다. JSON 파일은 필요 없습니다. 화면이 이미 열려 있는 동안 즉시 바뀌지는 않으며, 관리자가 코드 배포를 완료한 뒤 즐겨찾기를 다시 실행할 때 새 화면으로 바뀝니다.

직원의 위킵 로그인과 조회 권한을 그대로 사용합니다. 중앙 사이트에는 화면 코드만 있으며, 실제 재고 자료·직원 비밀번호·위킵 로그인 쿠키를 저장하지 않습니다.

끌어 놓기가 안 될 때

주소 복사를 누르고, 크롬 즐겨찾기 관리자에서 새 즐겨찾기의 URL로 붙여 넣으세요.
