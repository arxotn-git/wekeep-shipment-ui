# 요미몬 위킵 중앙 업데이트

이 저장소는 화면 코드만 제공합니다. 실제 재고 자료, 직원 비밀번호, 로그인 쿠키를 업로드하지 마세요.

직원은 위킵에 로그인한 뒤 홈페이지에서 등록한 즐겨찾기를 실행합니다. 최초에만 새 즐겨찾기를 설치합니다. 이후 버튼·기능 변경은 shipment-dashboard.js만 수정·배포하면 다음 즐겨찾기 실행에 반영됩니다. 화면이 이미 열려 있는 동안 즉시 바뀌지는 않습니다.

직원별 조회는 각 브라우저의 위킵 로그인과 권한을 사용하며, 검색할 때마다 위킵에서 읽습니다. 서버에는 회사 자료를 전송하거나 저장하지 않습니다.

## 관리자가 지켜야 할 것
- shipment-dashboard.js의 파일명과 게시 주소를 유지하세요.
- 버전 문자열을 바꾸지 않아도 새 코드를 실행할 때 기존 화면을 재구성합니다.
- 배포 완료 후 실제 위킵 탭에서 테스트하세요. 직원이 조회 중 다시 즐겨찾기를 실행하면 이전 조회는 취소하고 새 화면을 표시합니다.
- 코드는 직원의 위킵 권한으로 실행되므로 저장소 수정 권한은 신뢰할 수 있는 관리자에게만 부여하고 GitHub 계정 보안을 유지하세요.
- 인터넷·게시 사이트 문제로 코드 로딩이 실패하면 경고하고 기존 화면이 최신 업데이트가 아님을 표시합니다.
- 등록한 주소가 바뀌면 즐겨찾기를 다시 등록해야 하므로 저장소와 파일 경로를 바꾸지 마세요.

실제 직원용 설치 페이지는 index.html입니다. 원본 JSON·비밀번호·토큰은 이 저장소에 올리지 않습니다.
